# Dhuroov Kumar Portfolio

A single-page dark developer portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/`

## Requirements covered

- Single-page responsive portfolio
- Smooth scrolling navigation
- Dark futuristic developer theme
- Profile photo in circular frame
- Skills, projects, achievements, education, certificates, contact, footer
- Mailto-based contact form
- Back-to-top button
- Light/Dark theme toggle

## Open locally

Open `index.html` directly in a browser, or serve the folder with any static local server if preferred.
